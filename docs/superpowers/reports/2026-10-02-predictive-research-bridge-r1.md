## Normal architecture

The existing attention/investigation producer retains `investigation-research-bank.v1` records. The new normal asynchronous consumer is `python -m trader.research.predictive_bridge`. It reads exact persisted Bank rows, verifies the complete retained question/plan/evidence/result/run chain through the original contracts, and registers frozen `PredictiveHypothesis` proposals before attempting numerical translation. The consumer is a product entry point, independent of tests and Kernel. It is opt-in and has not been deployed.

```text
observation → attention → investigation → retained descriptive Bank result
→ bounded question → immutable hypothesis → existing quantitative planner
→ thresholds → window control → ablations → evaluation → protected referee
→ linked Bank feedback / revised question
→ candidate pointer only if existing Factory gate_evidence admits it
```

The hypothesis binds the exact source IDs, Research Bank identity, source code/version manifest, registration evidence, catalog/protocol, instrument, timeframe/horizon, as-of and availability timestamps, classification, and frozen prior recall. Each retained record is rebuilt and its immutable ID/hash verified. Missing provenance, incompatible contracts and descriptive records claiming trading/predictive authority are refused.

`QUESTION`, `HYPOTHESIS`, `SUPPORTED_RESULT` and `STRATEGY_CANDIDATE` are separate roles. A hypothesis contains a mechanism question, exact predictor and target, optional direction, horizon, universe, retained source context, falsification criteria, required data and leakage boundary. There is no LLM path in this package. Generation uses two finite registered deterministic transformations:

* `volume_breakout_context.v1` asks whether the existing `volz96>p90` context combined with `ev:donch100` improves fixed-geometry net returns under the existing policy. This is a proposed new price question, not a conclusion from the volume observation. It tests both existing planner mirrors, with no inferred directional authority.
* `exact_volume_path.v1` preserves the original volume-path question. The current quantitative planner cannot express its target and returns `UNSUPPORTED_EXPERIMENT_SHAPE`; no strategy is invented to fit it.

Source world/attention context is frozen provenance, not a learned trading predicate or a new numerical gate. The expressible template uses the registered volume predictor and registered universe. It does not infer a regime filter from prose.

Before registration, deterministic prior classification records `NEW`, `EXACT_DUPLICATE`, `RELATED_PRIOR` or `CONTRADICTED_BY_PRIOR`. Exact duplicate semantics exclude scan IDs and transient registration identity. An exact duplicate creates no new work. Material retained context differences remain related proposals, subject to all normal gates. Contradictions are context, not an automatic suppression policy.

Next questions handle descriptive support, refutation, unsupported/inconclusive measurements, missing data, unsupported shapes, retained contradictions and unexplained context. Existing registration-time memory recall is verified and frozen. Generation is at most two proposals/questions per source or feedback event, with deterministic order, no recursive question enqueue, at most sixteen new sources and four translation/submission attempts per cycle, append-only capacity-limited checkpoints, process deadlines and a single checkpoint lock.

## Protected quantitative path and authority

Translation uses existing registered policies/constants only. Each experiment freezes its predictor/target/horizon, calendar split, universe, null/control/ablation protocol, metrics, evidence floors, falsification rule, configuration, and source hypothesis ID. Rehashed changes to the null, metrics, direction or leakage guard are refused. Unsupported shape and data shortage are explicit outcomes.

All numerical candles, including warmup, open after hypothesis creation and the existing availability guard and are closed by the experiment as-of. Metadata scans read counts/timestamps, not protected prices. Thresholds use discovery only; protected A/B scores remain referee-only. Each experiment owns a frozen post-generation candle copy and a numerical ledger. `Combination.evaluation_scope` prevents collisions with historical combinations while preserving all default legacy identities. Existing controls, mandatory ablations, nulls, power, dependence-corrected Gate 1, cumulative LORD looks and Gate 3 remain in the existing runner/referee. There is no parallel statistical validation engine.

The bridge imports the exact initial protected-test budget from the supplied quantitative journal and accumulates all spent looks across its isolated ledgers. It recovers committed looks before offering further work after a crash. A changed source journal history or checkpoint binding refuses continuation. Use one configured checkpoint path and an exclusive asynchronous research consumer; this package does not coordinate independent competing research writers or deploy a scheduler.

Feedback distinguishes `SUPPORTED`, `UNSUPPORTED`, `INCONCLUSIVE`, `NOT_TESTABLE` and `DATA_INSUFFICIENT`. Pending or discovery-only results never count as predictive support. Bank attachments retain exact hypothesis → experiment → measurement → referee links separately from the original immutable v1 Bank schema. The verified reader is `trader.cognition.predictive_bank.predictive_extensions`.

Only `referee_passed` plus the existing Factory `gate_evidence` can produce a candidate pointer. The bridge imports no Factory writer and creates no StrategyVersion, install, paper approval, activation, allocation or execution. An external Factory caller can consume admitted fixture evidence through its unchanged universal gates. Stage7 RESEARCH capture/replay retains typed outcomes and exact dependencies; learned priorities do not enter statistical truth gates.

Production `research.referee=false` and `research.handoff=false` remain closed. Fixture referee execution is explicitly isolated. The local consumer also forces handoff off.
