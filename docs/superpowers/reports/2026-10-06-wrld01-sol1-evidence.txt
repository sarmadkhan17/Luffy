ACTUAL GAPS
1. Vote/meta had no complete typed measurement declarations or strict replay
   decoder. Decision consumed independent Vote fields and accepted untyped
   analyst output; source refs, quality, uncertainty and limitations were
   not a complete normal-path contract.
2. Value used the scalar zscore fallback: a constant/undefined window became
   zero and was reported as near fair value. Absent input branches projected
   positive confidence despite no measurement. Nonfinite required inputs
   could reach heuristic calculations rather than a null measurement.
3. Positioning retained the injected trading exchange even though evaluation
   never needed it. Positioning/Depth ignored injected context symbol identity.

CHANGE
Immutable analyst.measurement.v1 packets are carried inside the established
Vote metadata wire; Vote.measurement returns the typed packet. This preserves
the journal/capture schema. Each enabled analyst declares required/optional
inputs, a horizon (explicit None for current Depth), and mechanism limitations.
Input digests bind supplied frame/context representations, including available upstream
metadata, without inventing a provider or historical publication clock.
Finite supplied inputs have UNKNOWN source quality and SUSPECT measurement
quality because this bridge does not independently verify provider clocks.
Confidence is declared heuristic reliability, not a profit probability.
Missing/invalid/unsupported measurements carry null strength and confidence;
zero remains only the legacy abstention projection. Missing optional inputs
retain their own status/reason/ref rather than becoming neutral observations.
Value leaves undefined z-score null. Positioning discards exchange capability
and ignores wrong-symbol/nonfinite contexts; Depth validates book identity.
Decision strictly decodes packets, checks analyst/instrument/capture identity,
and derives scoring projections from the typed packet. Untyped/invalid output
is refused and logged, never synthesized. Historical untyped votes remain
untyped. Packet reload requires every wire field and validates source refs.
