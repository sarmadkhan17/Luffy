Authoritative measurement: `trader/cognition/contracts.py:volume_z` computes
the signed log1p anchor-volume z-score against the preceding N volumes, using
sample stdev followed by fmean, at full precision. `volume_measurement` shares
that result only inside one detached Dataset. The cache key contains the cut,
timeframe, duration and every immutable Candle field; the lookup also requires
the exact symbol. Availability, source, instrument/revision identity embedded
in source, prices and volume must all agree. No symbol normalization, global
cache, disk cache, or reuse of externally supplied WorldModel values occurs.
Only the latest window per symbol is retained, including a legitimate None.

The duplicate inline arithmetic in Attention and the WorldModel producer has
been removed. Active perception names and wrappers remain replay contracts.
No WorldModel schema or perception version changed because the resulting
measurements, statuses, records and IDs are byte-identical.

## Producers, consumers and meanings

| Path | Contract retained | Change |
| --- | --- | --- |
| Detached capture -> Store -> `world_producer.evaluate` | Captured closed candles and membership, exact scan cut | Load Dataset once and share it with Attention |
| `world_producer.build` -> `perceive` | N+1-volume window, typed signed intraday z-score, quality, uncertainty, provenance, hierarchy | Use authoritative scalar calculation and local exact-window reuse |
| `cognition.attention.evaluate` | N+S+1-bar return eligibility, volume component, salience, ranks, admission, frozen priorities | Request the exact N+1-volume measurement after existing eligibility checks |
| Persisted WorldModelRecord -> `world_producer.replay` -> adapter | Record/hash/cut validation and independent candle rederivation; tampering refused | Rederivation populates the same local measurement for subsequent Attention |
| WorldContext/history -> strategy/research feature queries | Exact scope, horizon, cut, quality and retained typed records | Unchanged |
| Claims, relationships, historical evidence | Immutable typed evidence and governed confidence, separate from measurement | Unchanged |

Equivalence is conditional on matching windows, rather than matching names.
Both default paths select the same 20 prior bars plus anchor, through the
same `Dataset.bar_asof` availability/revision contract and timeframe grid.
Attention's additional five return-history bars do not enter volume statistics.
Custom Attention windows retain their own measurements. WorldModel may validly
observe volume while Attention refuses an asset for insufficient return history
or degenerate return scale. Their status vocabularies remain independent:

- Missing anchor: producer STALE; Attention stale or missing.
- Hole/short volume history: producer MISSING; Attention gap or warmup.
- Malformed volumes: loader rejection or explicit producer INVALID on a direct
  adapter; no substituted zero.
- Undefined volume variance: scalar None; producer INVALID and Attention's
  volume component degenerate, with other valid components still available.
- Conflicting candle identities at the same revision coordinates: existing
  loader refusal remains in force, before any measurement.

The strategy DSL's `features.py:volume_z` is a different observable: raw volume,
rolling baseline including the anchor, a configurable window and series output.
Investigation's prospective mean-volume outcome uses future targets and a
frozen baseline. Neither is consolidated or edited. External WorldModel
observations remain independently validated competing evidence; they never
replace the candle component. The opt-in flag, default settings and all
admission/prioritization/strategy rules remain unchanged.

Function-call profiling was separate from timing: the combined path reduces
`load_input` calls 2 -> 1; both shared paths reduce volume fmean/stdev work by
50%. Return-scale statistics remain. Standalone separate produce/evaluate
calls use separate datasets and intentionally do not share state.

Actual cache microbenchmark: raw numeric median **58.176 us**, exact-window hit
**0.644 us**, changing-cut miss **61.184 us** (nine batches of 2,000 calls).
Thus a miss adds approximately **3.008 us** over the raw helper in this sample.
One populated cache's container/reference/result storage is **544 bytes**;
Candle objects are referenced, not copied. There is no persisted cache.

Runtime is platform/workload dependent and the host had other work running.
The singleton replay sample regressed; singleton Attention-only also varied
upward (0.722 -> 1.017 ms). No uniform latency improvement is claimed. Exact
calculation counts, bounded cache behavior and byte parity are deterministic
results, independent of scheduler noise.
