This is source and offline fixture evidence against baseline `4deca5c275c30c2c59c227b5170bab651cf777fe`, not a running-system observation. The inventory remains the original Review01 JSON/CSV; no new ownership census.

- **Authored knowledge → runtime narrative:** `Vault.__init__` copies `knowledge/` into `data/knowledge/` only when the latter is absent; existing runtime notes survive reconstruction. `Kernel._maybe_resolve_outcomes` refreshes strategy/daily/ledger/MOC notes on the retained hourly tick. `postmortem.run_postmortem` records a brain event and writes an incident only when verdicts change. `scripts/seed_vault.py` is explicit initialization, not a runtime scheduler. Org wraps are descriptive organizational links, not module-loading or command authority.
- **Retrieval and provenance:** `scripts/memory_lookup.py` reads authored frontmatter, excludes `status: candidate`, and resolves exact titles or exact reverse relations. Root probes resolve Absorption and the two recorded works_in/Ranging Regime concepts. The dashboard's `owner_api.knowledge` projects typed relations/wikilinks as written and labels notes context_only/file_modified, not causality/event truth. `owner.knowledge.enrich` adds exact stored query records and declared allowlisted code references; it does not use Graphify. The tracked-vault projection has 168 notes, 683 edges, 327 unresolved edges. Unresolved targets and candidate disagreement do not prove a missing required implementation.
- **Knowledge → intelligence:** `Kernel._strategist_knowledge` loads frozen operating doctrine and Harvester coverage; `_mechanism_once` passes these through the existing `SpecWriter.write` path. It does not automatically feed the authored atomic vault into research, strategy admission, Risk or execution. `brain.doctrine.load_doctrine` is read-only; no frozen doctrine rewrite was added. Established research memory lives in research ledgers/Research Bank and exact owner queries. Broader semantic transfer and historical-intelligence coverage remain partial under `STATE.yaml:knowledge_and_memory` and SDD20/34. No alternate retrieval/learning service was introduced.
- **Legacy/adaptive:** calibration/EWA/meta-label writing refuses through `learning.foundation.refuse_legacy_learning`; current decision machinery does not invoke these as a live adaptive capital authority. Their fitting/math/read APIs and tests remain historical compatibility. Config enabled flags and old prose alone do not prove activation. Genome/Pine/backtest utilities still have offline and compatibility consumers. `strategy.legacy_authority.grandfathered` binds exact definition hashes and pre-boundary owner grants. Factory probation filters finite monetary observations, verifies identity/exit semantics and costs, and rejects incomplete evidence before using `promotion.stats_of`. Legacy descriptive stats are not a second admission policy.
- **Conversation:** dashboard `/api/chat` → `ChatEngine.handle` → `AnalystAgent.run` → finite `owner_query` → `owner.queries.query` → exact record IDs/hashes/time/verification labels. The revised dispatcher enforces the advertised tool/argument boundary. Citation gating rejects no-evidence/no-consulted-ID replies, but it does not semantically verify every sentence merely because one consulted ID appears; no real-provider answer-quality claim is made. Legacy helper APIs remain compatibility, with missing/estimated P&L classified by the existing economics reader.
- **Notification:** caller records or computes state → `Telegram.send` → one bounded HTTP request. The transport now requires Bot API `ok=true` as well as HTTP success and avoids token-bearing exception strings. It remains best effort: most callers do not persist or retry failed sends, and API acknowledgement is not proof the owner read the alert. No new queue/retention/authority was added. Kernel owner controls still pass through the authenticated typed gateway; Telegram itself has no trade authority. Macro release messages follow recorded Supervisor outcomes; RentKeeper records its verdict before sending. Size-detected exits record estimated accounting and now explicitly announce **estimated pnl**, with a two-case failing-before and passing-after notification regression. This caller-only text change does not alter calculation, fills, booking or control state.
