## Attention reuse decision

`observability/positioning.py:read/attach` already offers a bounded read-only exact-cut retained-revision projection for funding and ls_ratio. `cognition/contracts.py` accepts those two optional series; `cognition/attention.py:_positioning` computes signed z against 20 prior samples, requires 21 continuous samples, rejects stale/gapped/degenerate series and uses the maximum absolute z. This is different from bar-window `funding_z`, OI change and analyst conviction; reusing any of those computed values as this score would change semantics.

There is no production caller of `positioning.attach` in this lineage. Normal `broad_crypto.observe` calls capture/evaluate without positioning or participation points; `observability/worker.py` persists supplied events. The optional consumer path is nevertheless real: evaluator observations/rows → store positioning_input → investigation replay, which uses the captured input and never re-queries today's derivs.db. `cognition/investigation.py` supports the positioning family. This does not establish that normal admission currently consumes positioning.

Retained ATT-03 evidence (`docs/tracker/evidence/att03-calibration-sol2/REPORT.md` and retained-positioning-results.json) reports no independent anomaly labels, no positioning input in frozen scans, one usable BTC funding series and stale BTC ratio/ETH series at its exploratory cut. It explicitly forbids injecting those readings into earlier scans. Conditional Gaussian normalization checks do not supply natural-series calibration or economic value. OI participation has only an optional supporting-evidence seam; normal capture does not supply it, and it is not a ranking term.

Therefore all proposed additions remain **DEFERRED**: attach positioning to normal broad admission; introduce OI participation/ranking; introduce macro/calendar ranking; reuse transient depth as historical liquidity or capacity; add caches or duplicate transforms. Enabling a dormant input could change discovery/admission ranking without a validated benefit. There is no proven redundant calculation with the same semantics and verified consumer that DA-07 should replace. Existing raw stores/loaders already serve strategy evaluation. No new machinery, historical backfill, thresholds, labels, policy, collection or provider calls were created.

Reopen only on a concrete consumer need and retained exact-cut observations with a frozen comparison that measures incremental investigation/strategy value and cost. Missing history, current membership and descriptive scores must remain missing/unknown rather than invented observations, labels or independent evidence.
