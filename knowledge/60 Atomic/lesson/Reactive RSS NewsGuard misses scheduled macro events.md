# Reactive RSS NewsGuard misses scheduled macro events

A reactive RSS headline scanner (NewsGuard) does not trigger on scheduled macro events like FOMC/CPI/NFP/Fed speeches because no severe headline appears before entry; a proactive calendar-based guard is required alongside reactive scanning.
