# Regime edge must be conditioned on direction accuracy

Regime-contingent edge should be evaluated using direction outcome accuracy rather than raw signal counts, because a SELL-heavy regime bucket (e.g., TRENDING_DOWN SELL n=41) is not evidence of edge while sell-side accuracy remains at 12.2%.
